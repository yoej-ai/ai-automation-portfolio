# Yoej Gramaje Jr. — AI Automation Portfolio

Static portfolio prepared for free hosting on GitHub Pages.

## Local preview

Run a static server in this directory:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

1. Create a public repository.
2. Push the contents of this folder to the repository's default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`.

No build step or paid hosting is required.
